# Between The Lines

This project is a libraryless (except for the java default libraries) 3D rendering engine, with the aim to build a multiplayer FPS game on top of it.

## How to run
As it is a Java+Maven based project, you will need said technologies. A regular build should do the trick.

## Current state & future
This project is very early on in development, currently only featuring the bare 3D->2D coordinate transformer and basic point rendering. The next steps in development are as follows:
- Triangles + z-ordering
- Adequate text rasterization
- First Person controller
- Guns, shooting, hit detection
- Servers + clients

If possible, pure console gameplay, similar to vim.
